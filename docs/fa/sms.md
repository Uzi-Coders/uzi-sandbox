# مستندات API سرویس پیامک (سندباکس)

یک سرویس پیامک آزمایشی برای توسعه و تست. قالب درخواست و پاسخ آن شبیه API پیامک [کاوه‌نگار](https://kavenegar.com) است، بنابراین کدی که برای این سندباکس نوشته می‌شود به‌راحتی با یک سرویس واقعی سازگار می‌شود. این پروژه **هیچ ارتباطی با کاوه‌نگار ندارد** و **هیچ پیامک واقعی ارسال نمی‌شود**؛ هر درخواست معتبر فقط در گزارش‌ها ذخیره می‌شود و به‌عنوان «رسیده به گیرنده» ثبت می‌گردد.

- **مسیر پایه:** `/sandbox/sms`
- **فرمت:** درخواست و پاسخ به‌صورت JSON
- **نکته:** پیام‌های خطا به زبان فارسی برگردانده می‌شوند.

## احراز هویت

هر درخواست API باید کلید API حساب شما را در هدر `X-API-Key` داشته باشد.

```
X-API-Key: <your-api-key>
```

| وضعیت | توضیح                                  |
|-------|----------------------------------------|
| 401   | هدر ارسال نشده یا کلید API نامعتبر است |

## ارسال پیامک

`POST /sandbox/sms/send`

### بدنه درخواست

| فیلد       | نوع  | اجباری | توضیح                        |
|------------|------|--------|------------------------------|
| `receptor` | رشته | بله    | شماره موبایل گیرنده          |
| `message`  | رشته | بله    | متن پیام، حداکثر ۹۰۰ کاراکتر |

فرمت‌های پذیرفته‌شده برای شماره (همه به‌صورت `09xxxxxxxxx` ذخیره و بازگردانده می‌شوند):

| ورودی           | مقدار ذخیره‌شده |
|-----------------|-----------------|
| `09123456789`   | `09123456789`   |
| `+989123456789` | `09123456789`   |
| `9123456789`    | `09123456789`   |

### نمونه درخواست

```bash
curl -X POST https://example.com/sandbox/sms/send \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"receptor": "09123456789", "message": "سلام!"}'
```

### پاسخ موفق (200)

```json
{
  "return": {
    "status": 200,
    "message": "تایید شد"
  },
  "entries": {
    "messageid": 1,
    "message": "سلام!",
    "status": 10,
    "statustext": "رسیده به گیرنده",
    "sender": 12345,
    "receptor": "09123456789",
    "date": 1767225600
  }
}
```

| فیلد         | توضیح                                       |
|--------------|---------------------------------------------|
| `messageid`  | شناسه رکورد پیامک                           |
| `status`     | در سندباکس همیشه `10` (رسیده به گیرنده) است |
| `statustext` | متن وضعیت                                   |
| `sender`     | شماره فرستنده اختصاص‌یافته به حساب شما      |
| `receptor`   | شماره گیرنده (نرمال‌شده)                    |
| `date`       | زمان ارسال به‌صورت Unix timestamp (ثانیه)   |

### خطاها

| وضعیت | علت                                                 |
|-------|-----------------------------------------------------|
| 400   | بدنه درخواست JSON معتبر نیست یا خالی است            |
| 400   | فیلد `receptor` یا `message` ارسال نشده یا خالی است |
| 400   | نوع `receptor` یا `message` رشته نیست               |
| 401   | کلید API ارسال نشده یا نامعتبر است                  |
| 411   | فرمت شماره گیرنده نامعتبر است                       |
| 413   | طول متن پیام بیشتر از ۹۰۰ کاراکتر است               |

نمونه بدنه خطا:

```json
{
  "error": "فرمت شماره نامعتبر است."
}
```

## پنل وب

`GET /sandbox/sms/panel` (نیازمند ورود)

گزارش پیامک‌های کاربر واردشده را از جدیدترین به قدیمی‌ترین و با ۱۰ مورد در هر صفحه نمایش می‌دهد. برای صفحه‌بندی از پارامتر `?page=N` استفاده کنید.

ورود از آدرس `/sandbox/auth/login` انجام می‌شود. حساب کاربری با دستور `python register_user.py` در خط فرمان ساخته می‌شود.
